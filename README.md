# Courier Life Simulator 3D

A browser-based 3D courier simulation prototype. The project is being developed as a mobile-friendly experience, starting with a playable vertical slice before expanding into a larger Indonesian-inspired delivery world.

## Planned technology

- React + TypeScript + Vite
- Three.js through React Three Fiber
- Drei for scene helpers
- Rapier 3D for physics (planned integration)
- Zustand for game state (planned integration)

## Development roadmap

1. Establish the application shell and a playable 3D prototype.
2. Add courier movement, motorcycle controls, and a small test environment.
3. Add warehouse parcel pickup and a first delivery mission.
4. Add rewards, progression, mobile touch controls, and save data.
5. Expand the world, traffic, NPCs, vehicle upgrades, and courier-company systems.

## Current status

The repository was initially empty. The first development milestone is the application foundation and a small playable prototype. Features listed in the roadmap are plans, not claims of completed implementation.

## Run locally

Once the application scaffold is in place:

```bash
npm install
npm run dev
```
